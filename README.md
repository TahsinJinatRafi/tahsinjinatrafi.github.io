# Tahsin Jinat Rafi — Personal Website

Responsive static website prepared for free GitHub Pages hosting.

## Preview
Open `index.html` in a browser, or use VS Code + Live Server.

## Publish free with GitHub Pages
1. Create a public GitHub repository named exactly `YOUR-USERNAME.github.io` (replace with your GitHub username).
2. Upload the *contents* of this folder to the repository root.
3. Open repository **Settings → Pages**.
4. Select **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
5. Your site will appear at `https://YOUR-USERNAME.github.io`.

## Update later
- Replace `assets/profile.webp` with a new photo using the same filename.
- Replace gallery images using their existing filenames.
- Add articles by editing `articles.js`; copy this object inside the `ARTICLES` array: `{ title: "Title", date: "2026-12-01", category: "Philosophy", excerpt: "Short summary", content: "Full article" }`.

The watermark is an overlay at the bottom-right only; it does not cover the face. Basic right-click/drag friction cannot prevent screenshots or determined downloads.

Location is currently displayed exactly as provided: `Tangail, Dhaka`; confirm the preferred public wording before publishing. Google indexing/ranking is not guaranteed.
